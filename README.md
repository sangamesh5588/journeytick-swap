> **JourneyTick Swap** is a verified peer-to-peer travel ticket marketplace and exchange community. It facilitates safe, transparent ticket transfers for travelers who can no longer attend trips or events.

---

## ✨ Features

- 🔄 **P2P Ticket Listing:** List unused bus, train, or event passes with seat category details.
- 🔍 **Route Search & Matching:** Search routes by origin, destination, and departure date.
- 🛡️ **Verified Traveler Trust:** Integrated user verification badges and safety guidelines.

---

## 🚀 Quick Start
```bash
git clone https://github.com/sangamesh5588/journeytick-swap.git
cd journeytick-swap
npm install
npm run dev
```
